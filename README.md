# Global Planner（B2B）

海外営業・貿易実務向けの **時差・現地祝日統合型「納期逆算＆日程調整」Web アプリ**です。
基準国（自社）と取引先各国の **タイムゾーン・週末・祝日** をまとめて扱い、複数工程の納期を順算／逆算し、
結果を海外顧客にそのまま送れる **英文メール / WhatsApp テキスト** として出力します。
貨物の寸法・重量からコンテナ／トラックへの積み付けを自動計算する **積載 3D シミュレーター（バンニング計算機）** と、
EXW 価格に物流諸掛・保険・関税を積み上げて条件別の提示価格を出す **Incoterms 輸出見積・コスト積算ボード** も備えています。

サーバー不要の静的サイト（Vite + React + TypeScript + Tailwind CSS）で、計算はすべてブラウザ内で完結します。
`main` ブランチへの push（PR マージ）で **GitHub Pages に自動デプロイ** されます。

## 画面構成

- **左ペイン（常に表示）**：対象国と営業時間。基準国・比較対象国・プリセット 6 か国・国検索。スクロールしても固定されます。
- **右ペイン（6 つのタブ）**：① 会議可能時間帯 ／ ② 納期計算 ／ ③ 稼働カレンダー＆ガント ／ ④ 英文メール / WhatsApp ／
  ⑤ 積載3Dシミュレーター ／ ⑥ Incoterms 輸出見積。表示中のタブは URL（`?tab=meeting` / `schedule` / `calendar` / `export` /
  `vanning` / `quote`）にも保存されるので、共有リンクで同じタブを開けます。

## 主な機能

### 1. マルチリージョン・時差＆祝日比較
- 基準国（既定: 日本）と比較対象国を複数選択。初期プリセット（この順に表示）：韓国 / 中国 / アメリカ / イギリス / ドイツ / インド。
  台湾・タイ・マレーシア・ベトナム・シンガポールなど約 200 か国を検索から追加可能。イギリスはイングランドの Bank Holidays（地域を選べばスコットランド等）で判定します。
- 国は「国旗画像＋日本語の国名」で表示（国旗は flagcdn.com の画像で、取得できない環境では同梱の SVG に自動で切り替わります。絵文字ではないので Windows でも文字化けせず、`JP` などの国コードも表示しません）。
- 各国の現在時刻と、営業時間（既定 9:00〜18:00）の **重なり＝会議可能時間帯** を 24 時間バーで表示。ホバーで全員の現地時刻を確認。
- 国ごとの週末定義（土日・金土など）、`date-holidays` による祝日の自動判定、州・地域の祝日、タイムゾーン（夏時間対応）を個別に設定可能。

### 2. 複数工程の納期 順算・逆算エンジン
- **順算**：開始日 → 最終納期 ／ **逆算**：希望納品日 → 発注デッドライン を切り替え。
- 工程（例: 国内手配・製造 → 海上輸送・通関 → 現地搬入）ごとに「所要日数」と「適用カレンダー（基準国営業日 / 相手国営業日 / 暦日）」を設定。テンプレートも用意。
- **計算結果サマリー**（最終納期・発注デッドライン・総所要日数・祝日でスキップした日数と祝日名）をリアルタイム表示。「ガントチャートで確認する →」でガントのタブへ。
- 日付計算は `YYYY-MM-DD` 文字列ベースの純粋関数（`src/utils/dateCalc.ts`）で実装し、閲覧者のタイムゾーンによる日付ズレが起きません。
- カレンダーの日付をクリックして **カスタム休日（旧正月・工場の長期休暇など）／臨時稼働日** を追加・解除。期間指定での一括登録も可能。

### 3. ガントチャート表示＆英文出力・共有
- 各国の稼働日（緑）・週末（グレー）・祝日（赤、ホバーで英語／現地語の祝日名）と工程期間を縦に並べて比較。
- 英文を 3 つの形式でワンクリックコピー：**Standard Email**（各工程の日程・スキップした祝日・関係国の祝日一覧）、**WhatsApp / Chat**（短い要約）、
  **Meeting Proposal**（相手国と営業時間が重なる直近 3 日を候補にした会議の打診。起点は「会議可能時間帯」タブで選んだ日付）。
- 選択国・工程・カスタム休日などを **URL クエリに自動同期**（URL を共有するだけで同じ状態を再現）。**LocalStorage へのプリセット保存** にも対応。

### 4. コンテナ・トラック積載 3D シミュレーター（バンニング計算機）
- 海上コンテナ（20ft Dry / 40ft Dry / 40ft High Cube）と国内トラック（2t / 4t ワイド / 10t）の内寸・ドア開口高・最大積載を内蔵。
- 貨物（木箱・パレット・カートン）を行ごとに入力：寸法 L×W×H、重量、個数、段積み可否（上積み厳禁）、90°回転の可否、識別カラー。
  T11型・ユーロ・T12型・北米パレットの寸法はワンクリックで入力できます。
- **緩衝材・隙間設定**：貨物間の緩衝材厚み（0〜500 mm）、壁面・周囲クリアランス（0〜500 mm）、上下段の間の緩衝材（0〜50 mm）、
  貨物ごとの個別緩衝材を設定でき、実効占有サイズで配置を計算します。陸路トラックは 貨物間 50 mm・壁面 30 mm が初期値
  （海上コンテナは 0 mm）。容積は「正味（Net Cargo Volume）」と「緩衝材込みの実質占有（Gross Occupied Volume）」を区別して表示し、
  3D では緩衝材を含めた占有境界を半透明のボックスで表示できます。
- 段積み不可・背の高い重い貨物から奥（前壁側）の床に置き、段積みできる貨物は高さ制限内で上に積む 3D 自動配置。
  積みきれない貨物、ドア開口高の超過、総重量オーバーは警告します。
- 「海上なら 20ft Dry で積載可能（余裕あり）」「陸路なら 4t トラック × 1台が最適」のように最適な規格と本数・台数を自動判定。
- 容積・重量・床面積の消化率メーター、three.js の 3D ビュー（回転・ズーム・パン、斜め俯瞰 / 真横 / 真上 / ドア側の視点切替）、
  規格名・積載量・貨物リスト入りの **PNG 画像保存**。貨物と規格は共有 URL にも含まれます。
- 英文メール / WhatsApp に **Packing & Container Summary**（総 m³・総重量・推奨コンテナ / トラック）を追記できます。

### 5. Incoterms 輸出見積・コスト積算ボード
- 社外・客先にも見せられるよう **製品原価・利益の項目は持たず**、EXW 価格（梱包込の工場出荷価格）に
  国内トラック運賃・輸出通関／港湾諸掛（FOB）→ 国際運賃（CFR）→ 保険料（CIF）→ 現地諸掛（DAP）→ 輸入関税（DDP）を積み上げます。
- 「積載3D」タブの貨物から **容積（Net m³）・総重量・コンテナ本数・トラック台数** を自動で引き継ぎ（手動で上書き可）、
  LCL の R/T（容積と重量トンの大きい方、最小 1.0）と Air の課金重量（実重量と 容積 × 167 kg の大きい方）を自動算出。
- 仕向地 × 20ft / 40ft / LCL / Air の目安運賃テーブル（日本発、約 40 か国の主要航路＋地域別の目安）に、
  市況（通常期 1.0x / 繁忙期 1.5x / 高騰期 2.5x）を掛けて運賃を算出。フォワーダーの実見積で上書きでき、運賃変動バッファ（0〜30%）を加算。
- 見積通貨（JPY / USD / EUR など）は **為替安全バッファ**（0〜10%）で厳しくした社内適用レートで換算。保険料は CIF の 110% に付保し、
  循環参照は CIF ＝ CFR ÷ (1 − 1.1 × 保険料率) で解きます。
- EXW / FOB / CIF / DAP / DDP の価格カード（外貨＋円、追加コストのバッジ）、コストが階段状に積み上がる積上げチャート、積算内訳表。
- 英文の **Incoterms Price Quotation**（EXW / FOB / CIF / DDP の価格・M3・重量・有効期限・Freight Disclaimer）をワンクリックでコピー、
  または「英文メール / WhatsApp」タブで単独の見積メールにしたり、Standard Email / WhatsApp に追記したりできます。入力はすべて共有 URL・プリセットに保存されます。

## 開発

```bash
npm install
```

```bash
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run build` | 型チェック（`tsc -b`）＋本番ビルド → `dist/` |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm test` | ユニットテスト（Vitest） |
| `npm run test:tz` | システムのタイムゾーンを変えてテスト（日付ズレがないことの確認） |
| `npm run lint` | oxlint |

Node.js `^20.19.0 || >=22.12.0` が必要です（CI は Node 20）。

## デプロイ

### GitHub Pages（自動デプロイ）

`.github/workflows/deploy.yml` が `main` への push（PR のマージ）ごとに `npm ci` → `npm run build` を実行し、`dist/` を GitHub Pages に公開します。Actions タブからの手動実行（`workflow_dispatch`）にも対応しています。

**初回のみ必要な設定**：リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に変更してください。

公開 URL：https://gogogorima.github.io/global-leadtime-planner/

`vite.config.ts` は `base: './'`（相対パス）なので、リポジトリ名やサブパスが変わっても設定変更は不要です。

### その他

`dist/` はそのまま任意の静的ホスティングに置けます。Cloudflare Pages の場合は Build command `npm run build` ／ Build output directory `dist`。

## 注意

- 祝日データは [date-holidays](https://github.com/commenthol/date-holidays)（データ: CC BY-SA 4.0）に基づく参考情報です。重要な日程は現地にご確認ください。
- UAE の祝日は、公式一覧（[閣議決定 2024 年第 27 号 / u.ae](https://u.ae/en/information-and-services/public-holidays-and-religious-affairs/public-holidays)）に合わせてアプリ側で補正しています（ツールチップに「補正」と表示）。年ごとの振替は公式発表に合わせてカスタム休日で調整してください。
- 宛名・署名などの出力設定はブラウザ内（LocalStorage）にのみ保存され、共有 URL には含まれません。
- 輸出見積ボードの運賃・諸掛・為替の初期値は目安です。実際の金額はフォワーダー・通関業者の見積や社内レートで上書きしてください。
